1. System Overview系統概述

The system is hosted on GitHub Pages and uses Firebase Realtime Database as the single source of truth. Every device (gate tablets, admin PC, teacher phones) reads and writes the same live data.系統託管於 GitHub Pages,並以 Firebase 即時資料庫為唯一資料來源。所有裝置(閘口平板、管理電腦、教師手機)均讀寫同一份即時資料。

2. Accounts & Access帳號與進入方式

  • One shared staff account (e-mail + password) unlocks the index page, Admin, Enquiry and the gate settings lock.系統設有一個共用職員帳號(電郵與密碼),用於進入入口頁、管理頁、查詢頁,以及解鎖閘口設定。
  • A separate kiosk account signs gate devices in silently; no password is requested when a gate page is opened.另設閘口專用帳號,閘口裝置開啟時自動登入,無需輸入密碼。
  • Passwords are managed in Firebase Console → Authentication. Change them after the event if desired.密碼於 Firebase 控制台之 Authentication 管理;如有需要,請於活動結束後更換。

3. Administration — Before the Event管理頁 — 活動前準備

3.1 Import Students匯入學生名單

Students tab → drop an .xlsx or .csv file. Columns: Student ID Card Number, Student ID, Class, Class Number, House. Choose Merge (update) or Replace All. The card number must equal the content of the QR code printed on the student card.於「Students 學生」分頁拖放 Excel 或 CSV 檔案,欄位為學生證卡號、學生編號、班別、學號、社;可選「合併更新」或「全部取代」。卡號須與學生證上 QR 碼之內容一致。

3.2 Competition & Helper Lists參賽者與工作人員名單

Upload the competition list and the student-helper list. Each upload replaces the whole list; any column containing a Student ID or Card Number is recognised automatically. The current list is displayed under each card.上載參賽者名單與工作人員名單;每次上載均取代整份名單,檔案中任何包含學生編號或卡號之欄位皆會自動識別,名單內容顯示於卡片下方。

3.3 Scenario & Threshold活動場景與超時時限

Settings → Event Scenario: Sports Day (Inside / Outside Stand) or Swimming Gala (Inside / Outside Venue). The overlong threshold (default 15 minutes) flags returns that exceed it.於「Settings 設定」選擇活動場景:陸運會(看台內/看台外)或水運會(場館內/場館外);超時時限預設為 15 分鐘,超過時限之返回將被標記。

3.4 Start Event Day開始活動

Press Start Event Day each morning. It clears all "outside" states and all phone-slot occupancy so the day begins clean.請於每日活動開始前按「開始活動」,系統會清除所有外出狀態與手機格占用,使當日由乾淨狀態開始。

4. Gate Operation閘口操作

4.1 Screen Layout畫面佈局

Header: gate name, scenario badge, channel badge, connection status and clock. The camera preview sits at the top; below it are the phone-slot strip and status pills (houses served, currently outside, time limit).頁首顯示閘口名稱、場景徽章、通道徽章、連線狀態及時鐘。鏡頭預覽位於畫面上方,其下為手機格條與狀態標籤(服務社、正在外面人數、時限)。

4.2 Exit Flow外出流程

  1. Student scans the QR code on the student card (or use Manual Entry).學生掃描學生證上之 QR 碼(或使用手動輸入)。
  2. The prefect taps the purpose: Toilet, Food, Competition, Student Helper or Other.風紀點選外出目的:廁所、小食部、參賽、工作人員或其他。
  3. Competition and Helper require the student to be on the uploaded list; otherwise the scan is rejected.參賽及工作人員必須於已上載之名單內,否則系統拒絕是次登記。
  4. Normal purposes receive a phone-slot number: place the phone in that slot. Competition and Helper keep their phones and have no time limit.一般目的會獲分配手機格編號,請將手機放入該格;參賽及工作人員無需交出手機,且不設時限。

4.3 Return Flow返回流程

  1. Student scans again at any gate serving them (Competition/Helper may return at any gate).學生再次掃碼返回(參賽及工作人員可於任何閘口返回)。
  2. The screen shows the time outside; collect the phone from the displayed slot.畫面顯示在外時間;請按顯示之格位取回手機。
  3. Returns exceeding the threshold raise a yellow caution and are flagged in the records.超過時限之返回會顯示黃色注意信號,並於記錄中標記。

4.4 Traffic Signals放行信號

PASS放行

Procedure complete; admit the student.手續完成,可讓學生通過。

STOP禁止通過

Wrong gate, slots full, already out, not found, or not on the required list. Do not admit; follow the on-screen reason.錯閘口、手機格已滿、重複外出、查無此人或不在所需名單內。不得通過,請依畫面所示原因處理。

CAUTION注意

Admit but take note: overlong return, previously overlong student, return without an exit record, or phone stored at another gate.可通過但須留意:返回超時、曾超時之學生、無外出記錄之返回,或手機存放於其他閘口。

4.6 Phone Slots手機存放格

  • Each gate owns 12 slots. When all 12 are occupied, further exits at that gate are blocked.每閘設有 12 個手機格;格位全滿時,該閘暫停辦理外出。
  • Tap an occupied slot to view the occupant: student ID, class, purpose, exit time, live elapsed time, trip count, registering device and today's trips.點選已占用之格位可查閱占用人資料:學生編號、班別、目的、離開時間、即時在外時間、外出次數、登記裝置及當日記錄。
  • Manual Return (staff password) releases a slot and writes a normal return record.「手動返回」(需職員密碼)可釋放格位,並寫入正常返回記錄。
  • Slots exceeding the threshold flash red and the header shows "⚠ n OVER".超時格位以紅色閃爍,標題列顯示「⚠ n OVER」。

4.7 Manual Entry手動輸入

The keypad provides digits 1–9, letters A–E, CLR and backspace. Accepted inputs: card number, student ID, class + number (e.g. 3B12), or class only (lists the whole class). Multiple matches produce a candidate list to tap.手動鍵盤提供數字 1–9、字母 A–E、CLR 及退格鍵。可輸入卡號、學生編號、班別加學號(如 3B12)或僅班別(列出全班);若有多個符合結果,將顯示候選名單供點選。

4.9 Gate Settings (password protected)閘口設定(需密碼)

Tap ⚙ and enter the staff password. Settings per gate: gate name (defines slot identity), houses served (two houses per gate; Competition/Helper exempt), mode (Auto / Out-only / In-only), channel type and sound.按 ⚙ 並輸入職員密碼。每閘可設定:閘口名稱(決定手機格身份)、服務社(每閘兩社;參賽及工作人員豁免)、模式(自動/只登記外出/只登記返回)、通道類型及聲音提示。

5. Teacher Enquiry教師查詢

  • Search by student ID, card number, class + number, or class.可以學生編號、卡號、班別加學號或班別搜尋。
  • The detail card shows current status (inside / outside with live elapsed time), purpose, slot, trip count and recent records.詳情卡顯示當前狀態(在看台內/外出中並附即時在外時間)、目的、手機格、外出次數及最近記錄。
  • Currently Outside lists every student outside now; Trip Board summarises today's trips and returned list.「正在外面」列出所有外出中之學生;「外出總覽」顯示當日外出統計與已返回記錄。

6. Administration — Records & Export管理頁 — 記錄與匯出

  • Records tab: choose a date range or use Today / Last 7 Days / All; the table lists every trip in range.「Records 記錄」分頁:選擇日期範圍或使用「今天/近7日/全部」快速按鈕;表格列出範圍內所有進出記錄。
  • Export Excel includes event, purpose, scanned value, phone slot, exit/return gates and times, duration and overlong flag.「匯出記錄」之 Excel 包含活動、目的、掃描值、手機格、出/入閘口與時間、在外時長及超時標記。
  • Summary exports per-student trip counts, purpose breakdown, total time outside and overlong counts.「匯出統計」按學生列出外出次數、各目的次數、總在外時間及超時次數。
  • Settings shows live phone-slot occupancy for every gate. Danger-zone clears require a second confirm press.「Settings 設定」即時顯示各閘手機格占用;危險區域之清除功能須按兩次確認。

8. Data & Privacy資料與私隱

  • Only card number, student ID, class, class number and house are stored; no student names are kept.系統只儲存卡號、學生編號、班別、學號及社,不儲存學生姓名。
  • All database reads and writes require an authenticated staff or kiosk account.資料庫之所有讀寫均須通過職員或閘口帳號驗證。
  • Exported files contain student identifiers; store them securely and delete them after use.匯出檔案包含學生識別資料,請妥善保管,並於使用後刪除。
